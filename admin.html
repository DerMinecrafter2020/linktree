    🎵 Navidrome / Subsonic

    Verbindet die Hauptseite mit deinem Navidrome-Server. Die Werte werden in localStorage gespeichert (nicht in Supabase, damit sie nicht öffentlich leak­en).

    🔐 Wo liegen die Credentials?

    Die Navidrome-Credentials (URL, Username, Passwort) liegen ausschließlich in den Supabase Secrets. Sie werden nie im Browser gespeichert.

    Du setzt sie einmalig im Terminal:

    supabase secrets set NAVIDROME_URL="https://navidrome.example.com"
supabase secrets set NAVIDROME_USER="dein_user"
supabase secrets set NAVIDROME_PASS="dein_pass"
supabase secrets set ALLOWED_ORIGINS="http://localhost:5500,https://deine-domain.de"

    Nach dem Setzen: „Status prüfen" klicken — die Edge Function meldet, ob alles da ist.

    🚀 Erste Einrichtung

    1. Edge-Function deployen (einmalig):
      supabase functions deploy navidrome-proxy
    2. Secrets setzen (siehe oben)
    3. Hier ☑️ „Player aktivieren" setzen, Speichern
    4. Hauptseite neu laden — Player erscheint
