API-Dokumentation

Öffentliche Endpunkte der OpenWeb Link-in-Bio Seite. Lesender Zugriff erfolgt mit einem API-Key aus dem Admin-Panel.

Profil abrufen

GET /api/public/profile

Gibt Name, Handle, Bio, Avatar, Theme und Sichtbarkeit des Profils zurück.

Header

X-Api-Key: dein-api-key

Beispiel-Antwort

{
  "ok": true,
  "data": {
    "name": "@corneliusahner",
    "handle": "Cornelius Ahner",
    "bio": "Azubi, 21 Jahre alt",
    "avatar": "CA",
    "avatar_url": null,
    "theme": "dark",
    "is_public": true,
    "allow_visitor_theme": true
  }
}

Links abrufen

GET /api/public/links

Gibt alle aktiven, aktuell sichtbaren Links inklusive Kategorie und Zeitsteuerung zurück.

Header

X-Api-Key: dein-api-key

Beispiel-Antwort

{
  "ok": true,
  "data": [
    {
      "id": 1,
      "title": "GitHub",
      "subtitle": "Code und Projekte",
      "url": "https://github.com/corneliusahner",
      "display_url": "github.com/corneliusahner",
      "icon": "simpleicon:github",
      "position": 0,
      "is_active": true,
      "open_new": true,
      "meta_description": null,
      "slug": null,
      "visible_from": null,
      "visible_until": null,
      "visible_weekdays": [],
      "category_id": 2,
      "category_name": "Social"
    }
  ]
}

Klick tracken

POST /api/links/:id/click

Speichert einen Klick für einen Link. Optional können UTM-Parameter mitgegeben werden.

Body

{
  "utm": {
    "source": "instagram",
    "medium": "bio",
    "campaign": "summer"
  }
}

Antwort

{ "ok": true }

Passwortgeschützten Link entsperren

POST /api/links/:id/unlock

Gibt die Ziel-URL eines passwortgeschützten Links zurück, wenn das Passwort korrekt ist.

Body

{ "password": "geheim" }

Antwort

{ "ok": true, "data": { "url": "https://example.com" } }
